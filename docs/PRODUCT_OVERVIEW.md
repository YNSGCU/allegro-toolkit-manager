# Product Overview

## Summary

Allegro Toolkit Manager (ATM) is a Windows desktop application for safely managing writable Allegro user configuration. It helps users inspect their environment, manage hotkeys, organize skills, and build ATM-managed menu overlays without directly editing shared company installs.

## User Value

- Safer config changes through preview and backup flows
- Better visibility into local Allegro environment state
- Reduced manual editing of `env`, `allegro.ilinit`, and generated IL files
- Clearer separation between company-provided assets and user-managed assets

## Major Capabilities

- Environment detection and health scoring
- Hotkey parsing, conflict detection, and profile application
- Skill scanning, loader generation, and profile management
- Menu-tree editing with validation and IL preview
- Unified Apply Plan and change history workflow

## Platform Assumptions

- Windows workstation
- Local Allegro user configuration under `pcbenv`
- Node.js/npm available for local development
