# 菜单方案跨电脑导入导出

## 功能说明

菜单方案可以导出为一个 `.atmmenu` 文件，再复制到另一台电脑导入。方案包保存菜单层级、命令、17.2 英文兼容显示名和来源 Allegro 版本，不包含 Skill 脚本。

## 适用场景

- 在办公室电脑和个人电脑之间同步一个菜单方案。
- 给同事分享菜单结构，但不共享整套 `pcbenv`。
- 从旧电脑的 `menu_profile.json` 中取回活动菜单方案。

## 导出方案

1. 打开“菜单”页面并选择需要分享的方案。
2. 若有未保存内容，先保存草稿。
3. 打开“工作区工具”，点击“导出当前方案”。
4. 选择保存位置，得到 `<方案名>.atmmenu`。

导出时会自动移除本机的 Skill 绝对文件路径，避免把旧电脑路径带到新电脑。中文名称、命令名和 17.2 英文兼容显示名都会保留。

## 在另一台电脑导入

1. 把 `.atmmenu` 文件复制到目标电脑。
2. 在 ATM“菜单”页面打开“工作区工具”，点击“导入菜单方案”。空菜单页面也有同名入口。
3. 核对来源方案、导入后名称、菜单数量、来源/目标 Allegro 版本和命令列表。
4. 点击“审阅导入计划”，在 Apply Plan 中确认写入。
5. 导入完成后检查新草稿，再点击“审阅并应用”生成目标电脑的 `generated_menu.il`。

同名方案不会被覆盖。ATM 会自动命名为“原名称（导入）”“原名称（导入） 2”等，并重新生成所有方案 ID 和菜单项 ID。

## 限制

- `.atmmenu` 只包含菜单方案，不包含 `.il` Skill 文件。目标电脑必须另外安装对应 Skill，否则菜单能显示但命令可能不可用。
- 从 17.4 导入 17.2 时，如果中文菜单没有“17.2 英文兼容显示名”，可以先导入草稿，但必须补齐后才能应用。
- 导入只新增草稿，不生成 IL、不修改已应用方案，也不立即改变 Allegro。
- 单个导入文件最大 5 MB；畸形 JSON、未知包版本、无效菜单树或超过 5000 项会被拒绝。
- 也可选择旧的 `menu_profile.json`；ATM 只导入其中活动的非空方案，不会整库覆盖。

## 排查

- 提示“菜单方案结构无效”：在来源电脑修复菜单树错误后重新导出。
- 导入后点击菜单没有反应：确认目标电脑已安装相同 Skill，并在 Skill 页检查命令是否已加载。
- 17.2 提示兼容显示名缺失：逐项填写 ASCII 英文名，再审阅应用。
- 导入后名称变化：表示目标电脑已有同名方案，这是防覆盖保护的正常行为。
