# 快捷键命令辅助与可靠编辑

## 功能说明

新增或编辑快捷键时，命令输入框会同时搜索 ATM 命令词典和当前工作区已有命令。建议项显示英文命令、中文名称、用途说明和来源范围。

例如，为物理键 `M` 新增绑定时，即使命令框尚未输入内容，也会以 `m` 作为提示线索，优先显示 `move（移动）`。也可以直接输入“移动”搜索 `move`。

## 使用方法

1. 在“键位”或“列表”页点击“新增绑定”。
2. 选择物理键和修饰键层。
3. 在“原始命令”中输入英文命令或中文用途。
4. 使用鼠标选择建议，或按 `↑` / `↓` 后按 `Enter` 填入。
5. 检查生成的 env 预览，再生成并确认 Apply Plan。

如果当前键位层已经存在同类型绑定，系统会阻止重复新增，并提示原命令。需要修改时应返回列表编辑原绑定。

## 编辑范围

- 可写 env 绑定：可以修改绑定类型、按键和命令。
- 当前方案绑定：还可以修改启用状态和备注，确认后真实更新方案 JSON。
- 安装默认 env、公司/参考 env、系统保留键、Skill 直接注册：只读，编辑入口会被禁用。
- 写入前会检查原始 env 行或方案内容是否被其他程序修改；内容变化时停止执行并要求刷新。

## 绑定类型建议

- `Funckey`：适合物理键、功能键和组合键。
- `Alias`：适合在 Allegro 命令行中输入的多字符缩写。

## 限制与验证

命令词典用于检索和解释，不等于当前 Allegro 版本已经验证该命令。词典中没有精确匹配时，界面会显示“未验证”提示。带分号、`FORM`、`prepopup`、模式切换或 SKILL 调用的复杂命令，应先在 Allegro Command 窗口验证，再写入 env。

参考资料中的复杂宏目前只作为设计参考，没有自动加入可信模板库。

## 故障排查

- 没有建议：尝试输入命令英文前缀、中文名称或用途关键词。
- “生成 Apply Plan”不可用：检查命令是否为空、键位是否已占用、实时检测是否失败。
- 提示文件被外部修改：关闭编辑框，刷新快捷键工作区后重新操作。
- 写入成功但 Allegro 没变化：根据 Apply Plan 提示重新加载配置或重启 Allegro，并先在 Command 窗口验证命令本身。
