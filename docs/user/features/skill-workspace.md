# Skill 管理工作台

## 功能说明

Skill 管理工作台用于集中查看 Allegro Skill 的来源、加载状态、入口命令、引用、健康度和诊断问题，并通过 Apply Plan 安全执行启停或方案切换。

## 适用场景

- 查找某个 Skill 或它暴露的命令
- 判断 Skill 是否正确加载、是否存在引用或冲突
- 启用、禁用用户/ATM Skill
- 切换 Skill 方案并预览实际文件变更

## 使用方法

Skill 页顶部使用紧凑方案栏和状态条，列表会自动占满窗口剩余高度。数据较多时，请在列表内滚动，页头和筛选条会保持可见。

子目录中的多文件 Skill 会按一个完整工具包显示。例如 `loader.il`、`main.il` 和多个内部模块会合并成一行，内部模块不再单独显示加载警告。“未配置启动加载”表示扫描到了工具包，但没有在 `allegro.ilinit`、ATM Loader 或其他启动源中找到它的入口。

1. 打开“Skill”页面，点击“重新扫描”。
2. 在“Skill 管理”中使用搜索、来源和加载状态筛选。
3. 点击列表中的 Skill，在右侧检查“概览、命令与引用、文件与加载、维护”。
4. 需要进一步排查时，进入“命令”或“诊断”视图。
5. 启停 Skill 或应用方案后，检查 Apply Plan，再确认执行。

高级筛选中提供引用状态、错误状态、排序和中英文名称显示模式。公司 Skill 始终只读，来源目录管理位于“更多操作”。

## 限制

- 较宽窗口中，点击 Skill 后使用左侧列表、右侧详情的分栏；窗口宽度不足时自动改用详情弹窗，避免列表被挤压。

- 页面必须在 Electron 应用内运行，普通浏览器没有 `window.atm` IPC 能力。
- 引用检查未成功执行前显示“尚未检查”，不会把未知状态标记成“无问题”。
- Skill 写入与启停不会绕过 Apply Plan。

## 故障排查

- 症状：列表为空。处理：确认环境路径后重新扫描，并检查来源筛选。
- 症状：诊断仍显示“尚未检查”。处理：检查 env 文件是否存在且可解析。
- 症状：应用后 Allegro 未变化。处理：确认 Apply Plan 已执行，并按提示重启 Allegro。
