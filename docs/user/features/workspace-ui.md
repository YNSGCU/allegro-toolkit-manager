# 新版工作区界面

ATM 使用同一套工作区界面。侧栏分为“核心工作区”和“系统”，共四个入口；原“概览”和“环境”合并为“系统状态”，环境详情仍可从系统状态页进入。

## 核心工作区

- 快捷键：只保留“键位”和“冲突”两个页签。键盘、搜索列表和编辑详情位于同一页；导入、导出、历史和 env 来源放在“工作区工具”。
- Skill：方案状态、筛选表格和详情检查器集中在单页工作区。默认只显示搜索和“筛选”，来源、加载状态、排序和显示方式在筛选面板中展开。
- 菜单：菜单树是唯一主工作区。命令清单和引用检查从“工作区工具”进入；添加命令、子菜单和分隔线统一使用一个“添加”菜单。

## 系统页面

- 系统状态：显示环境健康度、核心工作区入口和关键文件状态，并提供环境详情入口。

## 安全确认

“应用到 Allegro”不会直接覆盖文件。系统会先显示 Apply Plan，其中包含目标文件、执行步骤、备份和是否需要重启。确认后才会执行写入。

## 窗口尺寸

建议使用 1220×820 或更大的窗口。较窄窗口会把页头操作和分栏自动改为纵向布局；页面文字不会跟随窗口缩小，键盘和表格会在各自区域内滚动，不需要手动调整缩放比例。

首次进入某个工作区时，页面可能短暂显示“正在加载工作区”。侧栏和导航会保持可用；页面资源准备完成后会自动显示对应工作区，不需要重复点击。

方案栏只显示当前方案、“方案管理”和一处应用状态。新建、复制、重命名、删除、导入和导出都在“方案管理”中。“已应用”表示该方案确实是当前写入 Allegro 的方案；切换方案只会预览，仍需点击“审阅更改”并确认 Apply Plan。尚未创建方案时显示“暂无方案”，不会出现无效的应用按钮。

快捷键状态条只有在数据成功载入并完成诊断后才显示问题数量。若环境或桌面桥接加载失败，会明确显示“加载失败 / 尚未检查”，并在页面内提供红色错误提示；此时“0 个问题”不代表检查通过，也不会被显示。
