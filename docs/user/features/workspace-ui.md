# 新版工作区界面

ATM 的五个页面现在使用同一套工作区界面。侧栏分为“核心工作区”和“系统”，页面顶部按“标题、方案、状态、操作”的顺序组织。

## 核心工作区

- 快捷键：总览、编辑、冲突、导入导出采用紧凑页签；键盘文字保持清晰固定字号，空间不足时可在键盘区域内滚动。
- Skill：方案状态、筛选表格和详情检查器集中在单页工作区。
- 菜单：菜单树、命令视图和引用检查共用固定编辑区；预览与次要操作位于“更多操作”。

## 系统页面

- 概览：显示环境健康度、核心工作区入口和关键文件状态。
- 环境：显示检测模式、路径解析优先级、目录/文件权限与 Windows 环境变量。

## 安全确认

“应用到 Allegro”不会直接覆盖文件。系统会先显示 Apply Plan，其中包含目标文件、执行步骤、备份和是否需要重启。确认后才会执行写入。

## 窗口尺寸

建议使用 1220×820 或更大的窗口。较窄窗口会把页头操作和分栏自动改为纵向布局；页面文字不会跟随窗口缩小，键盘和表格会在各自区域内滚动，不需要手动调整缩放比例。

方案栏只显示当前方案和一处应用状态。“已应用”表示该方案确实是当前写入 Allegro 的方案；切换方案只会预览，仍需点击“应用方案”并确认 Apply Plan。
