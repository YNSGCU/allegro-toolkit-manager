# DRC 设计问题报告可视化

## 功能说明

DRC 看板把 Allegro 导出的 DRC 报告从纯文本变成可分组统计、可跟踪状态、可过滤导出的工作台。
支持两种数据来源：

- **导入报告文件**：导入 Allegro 导出的 Design Rules Check 报告（`.rpt`）或 Extracta CSV。
- **在线抓取**：通过 Vibe Bridge 从当前打开的 Allegro 会话直接读取 DRC 数据，无需手动导出文件。

## 导入报告文件

1. 在 Allegro 中执行 DRC 检查并导出报告（`.rpt` / CSV）。
2. 打开 ATM「DRC 看板」页面，点击「导入报告」。
3. 选择报告文件，预览解析结果（格式、设计、版本、错误/警告数量）。
4. 点击「确认导入」。相同内容的报告会自动去重，不会重复保存。

## 在线抓取

1. 在 Allegro 中打开需要检查的板子，并加载 Vibe Bridge 服务（`skill load(".../vibe_server.il")`）。
2. 确保 ATM 侧栏选择了与当前会话一致的 Allegro 环境。
3. 点击「在线抓取」。抓取前会先核对连接与版本匹配，版本不一致会拒绝执行。
4. 抓取结果会先预览，确认后保存为报告。

## 分组统计与筛选

选中报告后，页面顶部显示总数 / 错误 / 警告 / 已解决 / 已忽略五个摘要卡片。

- **分组 Tab**：按层、网络、规则、类型四个维度查看占比条形图，点击某一项即下钻筛选，再次点击取消。
- **搜索**：按规则码、描述、层、网络、元件等关键词过滤。
- **严重度 / 状态**：可分别按错误/警告、未处理/已解决/已忽略过滤。

## 状态跟踪与原文回看

- 明细表中每条违规都可以标记为「未处理 / 已解决 / 已忽略」，也可按当前筛选结果批量标记。
- 状态只保存在 ATM 本地（`drc/` 目录），不会修改 Allegro 设计数据库；「已忽略」不等同于设计侧豁免。
- 点击明细中的坐标可以打开原始报告并定位到对应行，方便核对上下文。

## 导出

点击「导出」选择 Markdown / HTML / CSV，导出的内容是**当前筛选结果**：

- Markdown：适合粘贴到文档或知识库。
- HTML：带样式的表格页，适合浏览器查看和分享。
- CSV：适合 Excel 或脚本二次处理。

## 限制与提示

- DRC 报告格式随 Allegro 版本和导出设置变化。ATM 尽量兼容常见结构，遇到无法识别的段落会跳过并给出解析提示；如果某版本报告解析不理想，建议改用「在线抓取」获得结构化数据。
- 报告只保留最近 100 份；删除报告会同时删除原始文件和状态标注。
- 在线抓取要求当前 Allegro 会话已加载 Vibe Bridge，且版本与 ATM 所选环境一致。
