# Allegro 会话控制台

## 功能说明

会话控制台通过 Vibe Bridge 实时查看当前 Allegro 会话，并执行 SKILL 命令：

- 查看版本、程序名、当前设计名与设计单位
- 执行只读或写 SKILL 命令，保留输出历史
- 写命令执行前会二次确认

## 打开控制台

在侧栏「核心工作区」点击「会话控制台」。页面顶部显示 Bridge 连接状态和会话快照。

## 刷新快照

点击右上角「刷新快照」重新探测当前会话。若 Bridge 未连接，会显示提示，请在 Allegro 中加载 `vibe_server.il` 并确保版本与侧栏所选环境一致。

## 执行命令

1. 在命令输入框输入 SKILL 代码，例如：
   ```
   list(axlVersion('fullVersion) axlCurrentDesign())
   ```
2. 点击「执行」。
3. 输出会追加到右侧「输出历史」，并标注只读 / 写命令与耗时。

也可以点击输入框上方的快捷命令按钮（版本信息 / 当前设计 / 设计单位 / DRC 数量），一键执行常用只读探测。

检测到可能修改设计的命令（如 `axlDBDeleteObject`、`axlDBChangeDesign`）时，会弹出确认框，确认后才执行。

## 限制与提示

- 只读命令不会修改设计；写命令仍有风险，请确认代码意图后再执行。
- 单条命令最长 20000 字符，超时默认 15 秒。
- 输出历史只在本次会话内保留，关闭应用后清空。
