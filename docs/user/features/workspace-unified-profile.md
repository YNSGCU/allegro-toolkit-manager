# 统一工作区方案

## 功能说明

统一工作区把 Allegro 环境、快捷键方案、Skill 方案、菜单方案和配色方案组合在一起。切换工作区只改变预览对象；只有点击“应用此工作区”并确认后才会写入配置。

## 使用方法

1. 从侧栏进入“工作区”。
2. 点击“新建工作区”并输入名称；创建后会自动打开配置窗口。
3. 选择 Allegro 环境，再选择该环境下的快捷键、Skill 和菜单方案；配色方案为全局选项。
4. 以后可通过工作区卡片上的“配置”按钮修改绑定，通过“复制”按钮创建副本。
5. 点击“预览”检查环境与方案是否存在。
6. 点击“引用校验”检查菜单/快捷键引用的命令是否由目标 Skill 方案中已启用的 Skill 提供。
7. 点击“应用此工作区”，确认目标名称和执行顺序后再执行。

应用顺序为 Skill → 菜单 → 快捷键 → 配色。某一步失败后会立即停止，完成数量只统计真正成功的步骤。

## 引用一致性校验

在切换工作区前，建议先点卡片上的“引用校验”。它会扫描当前环境中的 Skill 命令，
与菜单方案、快捷键方案的命令逐一比对：

- 命令由目标 Skill 方案中已启用的 Skill 提供，或属于 Allegro 内置命令：通过；
- 命令只由**未启用**的 Skill 提供：警告“应用后命令将失效”，并列出提供者；
- 命令找不到任何提供者：警告“未找到提供命令的 Skill，也不在内置命令表内”。

校验结果是提示性质，不阻止应用；是否阻断仍由各方案自身的校验决定。

## 方案导入导出与换机重绑

- 导出：工作区卡片上的导出按钮生成 `*.atm-workspace.json`，只包含组合关系和各子方案名称；
- 导入：在另一台电脑上点击“导入方案”，如果某些子方案在本机不存在，导入弹窗会按名称
  推荐最接近的本地方案，下拉选择后确认导入即完成重绑；也可选择“不绑定，导入后手动配置”。
- 导入始终创建新工作区（重名自动追加“（导入）”），不会覆盖本机现有方案。
- 本机存在同名 ID 的子方案时无需重绑，直接沿用。

## 安全限制

- 工作区绑定了环境时，当前活动环境必须与其完全一致；没有活动环境也会阻止应用。
- 默认工作区和当前使用中的工作区不可删除。
- 工作区定义保存失败时会显示错误，不会提示成功。
- 应用计划只能执行主进程刚生成且未经修改的版本。

## 故障排查

- 提示“当前激活为未设置”：先到环境页选择目标 Allegro 环境。
- 下拉框没有方案：先在对应功能页创建方案，然后重新打开配置窗口。
- 方案显示不存在：该方案可能属于另一个 `pcbenv`，请检查工作区绑定环境。
- 导入后提示方案缺失：在导入弹窗的“缺失方案”下拉中选择本机对应方案，或导入后在配置窗口中重新绑定。
- Vibe Bridge 未运行：配色页会显示当前电脑实际的 `vibe_server.il` 加载命令，不应出现其他用户的目录。
