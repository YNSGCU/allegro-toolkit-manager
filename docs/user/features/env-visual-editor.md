# Env 可视化编辑器

## 功能说明

Env 编辑器把当前 Allegro 环境的 `env` 文件按条目可视化展示，无需手改文本文件即可新增、修改或删除配置。支持三种可编辑条目：

- **快捷键**（funckey）：`funckey F1 zoom fit`
- **别名**（alias）：`alias zc zoom center`
- **变量**（set）：`set path = . C:/work/lib`

注释、空行和无法识别的原始行会原样保留，不会被编辑器破坏。

## 打开编辑器

1. 在侧栏「系统」分组点击「Env 编辑器」。
2. 确保侧栏底部已选择目标 Allegro 环境；编辑器只操作当前环境的可写 `env`。
3. 页面加载后即可看到当前 env 的条目列表和编码（GBK / UTF-8）。

## 新增 / 编辑 / 删除

- **新增**：点击右上角「新增条目」，选择快捷键 / 别名 / 变量，填写键名和命令（或值）。
- **编辑**：点击条目的铅笔图标，修改类型、键名或命令。
- **删除**：点击垃圾桶图标，条目会标记删除；再点一次可恢复。新增未保存的条目会直接移除。

编辑和删除只会进入「待应用」草稿，不会立即写入文件。顶部状态栏会显示待应用数量。

## 审阅并应用

1. 点击右上角「审阅并应用」，查看每处改动的前后对照（新增 / 修改 / 删除）。
2. 确认无误后点击「应用这些改动」。
3. 写入前会自动备份当前 env，并记录变更历史；失败时自动回滚。
4. 写入成功后需重启 Allegro 才会生效。

## 限制与提示

- 只编辑当前环境、可写的用户 env；Allegro 安装目录、公司或站点级 env 不提供编辑入口。
- 删除采用「注释原行」而不是物理删除，便于撤销。
- 如果 env 在编辑器打开后被其他程序修改，应用时会提示重新加载，避免覆盖外部改动。
- 命令或值包含空格时，编辑器会自动加引号。
