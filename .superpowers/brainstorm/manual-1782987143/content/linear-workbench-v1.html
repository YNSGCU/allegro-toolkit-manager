第一带：键盘占用总览

作为整页主角，做成一整块连续画布，而不是再被切成若干并排小统计卡。

第二带：命令与方案编辑

把方案切换、增删、导入导出收进同一条操作带，让人感觉是在处理一个流，而不是翻一堆功能盒子。

第三带：列表 / 冲突 / Apply Plan 预览

底部再进入更细的操作层级，这样主次会更强，页面不再到处都是同等级的框。

侧边辅助

只保留需要随时看一眼的信息，比如 env 来源、草稿状态、风险提示。

冲突提示

当有错误时，侧边栏变成提示轨道，而不是额外再长出几块统计卡。

你现在看到的差异

核心不是换颜色，而是减少“并排小盒子”，改成“大区块 + 工具带 + 主画布 + 辅助轨”。
